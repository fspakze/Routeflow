⚠️ Edge Functions ที่ต้อง deploy (ครั้งเดียว)

การสร้าง/ลบบัญชีต้องผ่านฟังก์ชันฝั่งเซิร์ฟเวอร์ (ปลอดภัย) — Supabase → Edge Functions → Deploy a new function แล้ว deploy 2 ตัว:
• admin-create-user ← โค้ดจาก supabase/functions/admin-create-user/index.ts (สร้างบัญชี)
• admin-delete-user ← โค้ดจาก supabase/functions/admin-delete-user/index.ts (ลบบัญชี)
• admin-set-password ← โค้ดจาก supabase/functions/admin-set-password/index.ts (ตั้ง/รีเซ็ตรหัสผ่าน)
(Supabase ใส่ key ที่จำเป็นให้อัตโนมัติ) · แก้สิทธิ์/ปิดใช้งาน/แก้ชื่อ ทำได้เลยไม่ต้อง deploy
